# 🚀 MyProjects - Portfólio de Projetos

Este repositório reúne diversos projetos desenvolvidos para estudo, experimentação e prática em diferentes áreas da tecnologia, incluindo desenvolvimento web, backend, algoritmos, robótica e sistemas embarcados.

O objetivo principal é consolidar conhecimento prático e demonstrar evolução técnica ao longo do tempo.

---

## 📌 Sobre o repositório

O projeto funciona como um **hub de projetos**, contendo múltiplas aplicações independentes, cada uma explorando tecnologias e conceitos diferentes.

Entre os principais tipos de projetos incluídos:

* 🌐 Aplicações web (HTML, JavaScript, EJS)
* ☕ Projetos em Java
* 🐍 Scripts e estudos em Python
* 🤖 Projetos de robótica e controle
* 💾 Simulações de sistemas (ex: banco, redes, etc.)

---

## 🧠 Principais Projetos

### 💳 Sistema Bancário (Web)

Aplicação web com funcionalidades típicas de um sistema bancário:

* Criação de conta
* Solicitação de empréstimos
* Cartões de crédito
* Transferências entre contas
* Histórico de transações

---

### 🗄️ Mini Database Engine (Java)

Implementação de um mecanismo simplificado de banco de dados em Java, abordando:

* Estrutura de armazenamento
* Operações básicas de CRUD
* Organização de dados

---

### 🤖 Projetos de Robótica

Inclui projetos voltados para controle e automação, como:

* Controle PID aplicado a rastreamento
* Integração com hardware (ex: módulos como nRF24L01)

---

### 🧪 Deep Q-Learning (DQN)

Projeto explorando conceitos de **aprendizado por reforço**, incluindo:

* Treinamento de agentes
* Tomada de decisão baseada em recompensa
* Simulações
